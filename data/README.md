# Data inventory and provenance

`figure_source/` contains the research outputs used by the figure renderer and verification script.

| Archived file(s) | Original project output | Scope |
|---|---|---|
| `figure1_water_annual.csv`, `boundaries/*` | `Figures/Fig1_location_water_extent_panels_2001_2024_source_data.csv`, basin and lake-extent source boundaries | Daily-water-derived annual series and a simplified basemap-free location panel |
| `figure2_*.csv` | `Figures/Publication/Figure2_CEE_vertical_excl_AralUnion/Figure2_source_data_*` | Annual area, net change, transition matrix |
| `figure3_areas.csv`, `figure3_maps.npz` | `Results/Figure3_AralUnion_Reclassified_Persistent_RecentState/Figure3_persistent_recentstate_*` | Native 30 m area table; display-sampled map arrays |
| `aral_water_union_30m.tif` | `Results/Figure3_AralUnion_Reclassified_Full30m/Aral_water_union_2001_2024_30m.tif` | Terrestrial exclusion mask |
| `figure4_*.csv` | `Figures/Publication/Figure4_MESMA_excl_AralUnion/Figure4_source_data_*` | Monthly and annual corrected MESMA fractions |
| `figure5_*.tif`, `figure5_*.csv` | `Results/Figure5_MESMA_Persistent_Degradation/Figure5_persistent_*` | First persistent event and three response components |
| `figure6_*.csv` | `Results/Figure6_PersistentMask_LakeShrinkage_Coupling/Fig6_persistent_source_*` | Persistent-mask monthly data, correlations and confidence intervals |
| `era5land_monthly.csv` | `Results/Climate_ERA5Land/Aral_ERA5Land_monthly_2001_2024_excl_AralUnion.csv` | Basin monthly climate variables and anomalies |
| `water_annual_shrinkage.csv` | `Results/DailyWaterbody_Aral_2001_2024/Aral_daily_water_percent_equivalent_area_2001_2024.csv` | Figure 7 annual shrinkage input |
| `figure7/*.tif`, `figure7_summary.csv` | `Results/Figure7_Persistent_Coupling_Reuse_Figure5/rasters/*_{r,p}_vs_*`, `tables/Figure7_persistent_coupling_summary_2001_2024.csv` | Full-resolution `r` and exact `p` rasters; summary |
| `boundaries/*` | Basin and 2001 water-extent boundaries | Location panel and subbasins |

The final terrestrial exclusion mask is `figure_source/aral_water_union_30m.tif`, which represents the study's 2001–2024 observed-water union. The downstream scripts consume this raster directly. Its upstream delineation from annual water observations is not reproduced in this compact package.

The following large inputs are intentionally excluded from the repository. For full processing, place them at these relative paths:

| Path under `data/raw/` | Required source | Years |
|---|---|---|
| `FROMGLC30_V002/<year>/...` | [FROMGLC30 V002](https://doi.org/10.12436/iEarth.0000.20251229.000066.v1) annual tiles | 2001–2024 |
| `daily_waterbody/...` | [Global 500 m Daily Water Body Mapping Dataset](https://data-starcloud.pcl.ac.cn/iearthdata/9) daily tiles | 2001–2024 |
| Annual water-occurrence tiles | Written to `outputs/full/waterbody/rasters/annual_occurrence_tiles/` by `waterbody_daily.py`; not needed when using the archived final mask | 2001–2024 |
| `annual_mesma/Aral_MESMA_Degradation_<year>.tif` | Study-generated annual MESMA fractions; bands must match the original five-band rasters | 2001–2024 |

The authors ran Sun et al.'s [public MESMA code and supplied endmembers](https://doi.org/10.5281/zenodo.10796386) in Google Earth Engine for the full 2001–2024 study period. The code, algorithm, parameters, preprocessing, and export scripts were unchanged. All 2001–2024 fraction data used in this study were generated by that run; Sun et al.'s separately published 2001–2022 fraction product was not used as an input. The study's monthly MESMA and ERA5-Land derived tables are archived here. Its annual fraction rasters and the third-party MESMA code and endmembers are not copied into this compact package. The compact Figure 1 location panel is drawn from boundary vectors without the original map background.
